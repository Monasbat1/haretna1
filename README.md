# حارتنا ✈️ — النسخة النهائية
ارفع محتويات هذا المجلد فوق موقعك (يستبدل city.js وahmadkaled1998.html ويضيف مجلد airbase):
- city.js — معدّل: زر ✈️ بالشريط الجانبي، المطار الحربي، الطيران فوق المدينة، القصف الحقيقي للبيوت والسيارات والمعالم.
- ahmadkaled1998.html — لوحة الإدارة + تبويب «✈️ الطائرة الحربية».
- airbase/ — jet.js (الطائرة+المطار) · flight.js (الطيران والأسلحة والدفاعات) · warjet.js (الربط بالمدينة) · admin-jet-patch.js · demo.html (معاينة مستقلة).
## التفعيل
1) لوحة الإدارة ← ✈️ الطائرة ← عدّل الموارد ← «إضافة/تحديث في المتجر» ثم 🚀 نشر.
2) المتابع يشتري ← تقبل طلبه من 🛒 الطلبات ← يُكتب owned/<user>/f_jet=1 ← يظهر له الطيران.
3) قواعد Firebase: اسمح بقراءة owned/$user/f_jet، والكتابة على owned للأدمن فقط.
## ملاحظات
- التدمير يظهر للاعب فقط ويعود بعد 45–90 ثانية (لا يمس بيانات أحد). بيت اللاعب نفسه محمي.
- للاختبار بدون شراء: افتح الموقع بـ ?freejet
- مكان المطار: city.js، الوسيط at (شمال مطار دمشق). غيّره إن تداخل مع بيوت.
- التحكم: WASD/أسهم، Space رشاش، R صواريخ عشوائية، L ليزر، E صعود/هبوط؛ على الجوال اسحب + أزرار.
